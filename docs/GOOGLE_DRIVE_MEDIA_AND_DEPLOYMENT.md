# دليل الوسائط عبر Google Drive والنشر

## تنبيه: هذا المسار مستبدل

> بناءً على قرار المؤسسة اللاحق، **لا يستخدم الموقع الحالي Google Drive أو Firebase أو Firestore**. يعتمد مسار النشر والمحتوى المعتمد الآن على GitHub وVercel فقط. ارجعي إلى `docs/GITHUB_VERCEL_CMS_SETUP.md` للإعداد الحالي. تبقى التفاصيل التالية كسجل تقني قديم ولا تُطبّق على النسخة الجديدة.

## ما الذي تغير؟

تستقبل لوحة الإدارة الآن **رابط مشاركة ملف من Google Drive** بدلاً من رفع الملف إلى Firebase Storage. تحفظ اللوحة رابط الصورة أو الفيديو مع العنوان والوصف والوصف البديل وبيان الحقوق وحالة النشر. لا يظهر للزائر إلا ما ينشره الفريق بعد التأكد من صلاحيته واحترام خصوصية المستفيدين.

> لا تضعي صوراً أو فيديوهات في Google Drive ببيانات تعريفية للمستفيدين، ولا تنشري مادة لا تملك المؤسسة حق استخدامها.

## إضافة صورة أو فيديو من Google Drive

| الخطوة | ما يجب فعله |
|---|---|
| 1 | ارفعي الملف إلى مجلد المؤسسة في Google Drive. |
| 2 | اختاري **مشاركة** ثم **أي شخص لديه الرابط**، مع صلاحية المشاهدة فقط. |
| 3 | انسخي رابط المشاركة من Drive. |
| 4 | افتحي «المكتبة» في لوحة الإدارة، واختاري صورة أو فيديو، ثم الصقي الرابط وأكملي العنوان والوصف والوصف البديل وبيان الحقوق. |
| 5 | ابدئي كـ«مسودة داخلية»، وغيّري الحالة إلى «منشور للعامة» فقط بعد المراجعة. |

يدعم النظام رابطاً من الشكل `drive.google.com/file/d/…` أو `drive.google.com/open?id=…`. يحول الموقع الرابط تلقائياً إلى عرض مناسب للصور أو معاينة للفيديو.

## ما يبقى محفوظاً وأين؟

| العنصر | الموقع |
|---|---|
| الملف الأصلي (صورة أو فيديو) | Google Drive الخاص بالمؤسسة |
| العنوان والوصف والحقوق والحالة | قاعدة المحتوى المستخدمة من لوحة الإدارة |
| كود الموقع الجديد | مشروع الموقع الحالي |
| الموقع القديم | مستودع GitHub `seheil/mashroana.org`، من دون تعديل تلقائي |

## GitHub وVercel

النسخة القديمة في GitHub ثابتة؛ كانت الملفات تُرفع يدوياً إلى `assets` ثم يُدفع التعديل إلى `main`. مشروع Vercel الظاهر حالياً لا يملك نشر إنتاج عاملاً، ولذلك لا ينبغي اعتباره وسيلة اختبار للموقع الجديد قبل ربط المستودع الصحيح وإصلاح إعداد النشر.

عند الاستعداد للنقل، يكون التسلسل الآمن: إنشاء نسخة احتياطية للمستودع، ربط **مستودع جديد أو فرع جديد** بالموقع الجديد، اختبار معاينة، ثم تفعيل النشر. لا تُحذف النسخة القديمة حتى تؤكد المؤسسة أن الموقع الجديد يعمل ويظهر المحتوى المعتمد.

## قبل النشر العام

يجب إنشاء قاعدة المحتوى في مشروع Firebase الصحيح أو اعتماد بديل مؤسسي لحفظ المحتوى؛ Google Drive يحفظ الملفات ولا يصلح وحده لحفظ نصوص الموقع وحالات النشر. بعدها يختبر المسؤول إضافة مادة مسودة، نشرها، وتأكيد ظهورها للزائر غير المسجل.
