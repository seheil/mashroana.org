# إعداد الموقع ولوحة المحتوى عبر GitHub وVercel

هذا المسار لا يستخدم Firebase أو Firestore أو Firebase Storage. ملفات المحتوى تُحفظ في مستودع GitHub، وكل تعديل منشور يعيد Vercel بناء الموقع تلقائياً. تعتمد لوحة المحتوى على GitHub OAuth؛ فهي لا تتصل بقاعدة بيانات مستقلة. توضح وثائق Decap CMS أن الخلفية الخاصة بـ GitHub تحفظ المحتوى في مستودع Git وأن الربط الخارجي يحتاج تطبيق OAuth ومساري `auth` و`callback`.[1]

## تسلسل النقل الآمن

| الترتيب | الإجراء | الهدف |
|---|---|---|
| 1 | لا تعدّلي المستودع القديم مباشرة. أنشئي نسخة احتياطية أو فرعاً جديداً باسم `site-v2`. | الحفاظ على الموقع القديم قابلاً للاسترجاع. |
| 2 | ارفعي كود الموقع الجديد إلى الفرع أو المستودع الجديد. | فصل النسخة الجديدة عن الأرشيف القديم. |
| 3 | في Vercel، استوردي المستودع وحددي أمر البناء `pnpm build` ومجلد الإخراج `dist/public`. | نشر نسخة Vite الثابتة. |
| 4 | بعد ظهور رابط Vercel النهائي، استبدلي `REPLACE_WITH_YOUR_VERCEL_DOMAIN` في `client/public/admin/config.yml` بعنوان Vercel الفعلي. | تمكين تسجيل الدخول إلى لوحة المحتوى. |
| 5 | أنشئي GitHub OAuth App واجعلي رابط الاستدعاء `https://YOUR-VERCEL-DOMAIN/api/callback`. | تأمين تسجيل دخول محرري المحتوى بحسابات GitHub المصرّح لها. |
| 6 | أضيفي في **Environment Variables** داخل Vercel القيم: `SITE_ORIGIN`، و`GITHUB_OAUTH_CLIENT_ID`، و`GITHUB_OAUTH_CLIENT_SECRET`. | حفظ السر خارج GitHub وربط لوحة المحتوى. |
| 7 | اختبري `/admin/` بحساب GitHub يملك صلاحية كتابة المستودع، ثم أضيفي مادة تجريبية كمسودة واحذفيها بعد التأكد. | التأكد من دورة التعديل ثم النشر. |

> لا تضعي `GITHUB_OAUTH_CLIENT_SECRET` أو رموز الوصول في ملفات الموقع أو رسائل المحادثة أو مستودع GitHub.

## أين يعدل الفريق المحتوى؟

بعد اكتمال الربط، يفتح المحررون `<رابط-الموقع>/admin/`. تتيح اللوحة تعديل البرامج والإنجازات والمكتبة والأولويات في `client/src/content/site-content.json`. تحفظ كل عملية تعديل في GitHub مع سجل تغييرات، ثم يعاد بناء الموقع عبر Vercel.

| نوع المحتوى | الملف | سياسة النشر |
|---|---|---|
| البرامج والإحصاءات | `client/src/content/site-content.json` | تنشر بعد مراجعة المسؤول. |
| الإنجازات | `client/src/content/site-content.json` | لا تستخدم أرقاماً أو صوراً غير موثقة. |
| الصور والفيديو | `client/public/uploads/` وبيانات `media` | لا تنشر قبل تأكيد الحقوق والخصوصية. |
| أولويات التبرع | `donationPriorities` في ملف المحتوى | لا تظهر إلا بالحالة `published`. |

## حدود يجب معرفتها

GitHub وVercel يصلحان للموقع الثابت وتعديل المحتوى عبر سجل تغييرات واضح. أما رسائل الزوار فلا تُحفظ في الموقع في هذه النسخة؛ يفتح نموذج التواصل وطلب الشراكة والتطوع رسالة WhatsApp مباشرة، ولا يعد الإرسال ناجحاً إلا بعد إرساله من WhatsApp. لا تستخدم بيانات تطبيق `mashrouana-app` أو قاعدة Firestore الخاصة به لأنها ليست موقع المؤسسة.
