# أنماط الشراكات المؤسسية القابلة للتطبيق

توضح صفحة [الشراكات المؤسسية لدى GiveDirectly](https://www.givedirectly.org/corporate-partnerships/) أن الحملة مع الشركات تبدأ بنموذج اهتمام وتقييم توافق القيم، ثم تتطلب عقداً وتحديداً واضحاً للمبلغ أو آلية التبرع ورسالة دقيقة للمستهلك، كما تقيد استخدام الاسم والشعار دون إذن. تختلف التفاصيل القانونية حسب الدولة، لكن المبدأ العام قابل للتبني: لا تعلن المؤسسة عن شراكة أو تستخدم شعار شركة أو تدعي حملة مشتركة قبل موافقة مكتوبة.[1]

تظهر صفحة [مطابقة تبرعات الموظفين](https://www.givedirectly.org/employer-matching/) أهمية تجهيز بيانات المنظمة ووسيلة إصدار إثبات للتبرع؛ وتوضح أن قبول المطابقة يعتمد على قواعد صاحب العمل. وهذه خاصية مستقبلية للمؤسسة بعد التحقق من الإطار القانوني، وتفعيل مسار تبرع يمكن تأكيده وإصدار إيصال منه، وليست مجرد حقل يضاف إلى الموقع.[2]

ويقدم نموذج [حديث مكان العمل](https://www.givedirectly.org/workplace-talk/) مثالاً منخفض الكلفة على الشراكة غير النقدية: جلسة تعريفية للشركة مع مواد عرض موحدة ونموذج اهتمام. يمكن لمؤسسة مشروعنا تبني نسخة محلية لاحقاً عبر «اطلب لقاء تعريفياً»، إلى جانب فرص دعم عيني وتطوع مهني، بدلاً من حصر الشراكة في طلب المال.[3]

## مواصفات نموذج «كن شريكاً» المقترح

| الحقل | الغرض |
|---|---|
| اسم الجهة وقطاعها وموقعها | فهم ملاءمة الشريك ونطاقه |
| اسم المسؤول ووسيلة اتصال رسمية | متابعة مسؤولة قابلة للتوثيق |
| نوع التعاون | تمويل، دعم عيني، تطوع مهني، حملة موظفين، مساحة/لوجستيات، أو تواصل |
| مجال البرنامج | ربط الطلب بالاحتياج أو البرنامج المناسب |
| القيمة أو النطاق التقديري | فرز أولي دون وعد نهائي |
| المدة المتوقعة | تصميم اتفاق أو خطة مناسبة |
| احتياج الشعار أو الحملة المشتركة | حماية العلامة والاعتمادات قبل النشر |
| الموافقة على معالجة البيانات | احترام الخصوصية وإذن المتابعة |
