# مقارنة أولية: مؤسسات مصرية مرجعية

## مؤسسة مصر الخير

يعرض موقع [مصر الخير](https://mekeg.org/ar) عناصر مفيدة قابلة للتبني تدريجياً: حالات عاجلة مرتبطة بمبالغ مستهدفة، تصفح البرامج حسب المجال، منتجات تبرع محددة القيمة، أخبار حديثة، قائمة شركاء، ومركز معلومات يتضمن مجلس الأمناء والتقارير السنوية والفروع والأسئلة الشائعة وسياسات الموقع.[1]

تُظهر صفحة [منتجات التبرع](https://mekeg.org/ar/donations/products) فائدة تحويل العطاء العام إلى «منتجات أثر» دقيقة الثمن والوصف، مثل شنطة مدرسية أو نظارة أو جلسة رعاية. هذه الممارسة تقلل الغموض أمام المتبرع، لكن لا ينبغي اعتماد سعر أو أثر في موقع مؤسسة مشروعنا إلا بعد مراجعة تكلفة البرنامج والقدرة التشغيلية الفعلية.[2]

## بنك الطعام المصري

يوفر [بنك الطعام المصري](https://www.efb.eg/ar) نموذجاً مفيداً في عرض القضايا العاجلة مع التقدم تجاه الهدف، وتصنيف البرامج حسب الفئة المستفيدة، وإظهار مؤشرات الأثر، وعرض الشركاء. كما يقدم فكرة «دائرة الإنسانية» التي تسمح بإنشاء دوائر جمع تبرعات للأصدقاء أو الزملاء؛ وهذه فكرة مستقبلية مناسبة فقط بعد تثبيت البنية التشغيلية وقواعد الحماية والقياس.[3]

## مؤسسة أهل مصر

تبرز صفحة [التبرع لدى أهل مصر](https://ahl-masr.ngo/ar/donate/) أهمية تنويع القنوات: بوابة الدفع، الحسابات البنكية، التحويل الدولي، التطبيقات، محافظ الهاتف، وخيار المتابعة الهاتفية. كما تربط التبرع ببرامج محددة وتقدم دليلاً واضحاً للتبرع بالزكاة من خلال جهة موثوقة. الدرس العملي للمؤسسة هو تنظيم طرق الدفع بحسب حالة المتبرع بدلاً من الاكتفاء بأرقام مبعثرة.[4]

## الاستنتاج المبدئي القابل للتنفيذ

| الممارسة | القيمة لمؤسسة مشروعنا | التنفيذ المقترح |
|---|---|---|
| منتجات أثر محددة | تجعل قرار التبرع واضحاً | إعداد قائمة داخل لوحة الإدارة بعد اعتماد التكلفة الواقعية لكل برنامج |
| صفحة برنامج تفصيلية | تربط المانح بهدف وفئة ومستهدف | إضافة حقول الهدف، التمويل، التحديث، والوثائق للمشاريع لاحقاً |
| طرق تبرع منظمة | تقلل فقدان المتبرعين | توحيد بنك مصر وInstaPay والمحافظ والتواصل في صفحة «كيف تتبرع» |
| شركاء موثقون | يعزز العناية الواجبة | عرض الشركاء فقط بعد موافقة مكتوبة أو شعار مصرح باستخدامه |
| أخبار وتقارير محدثة | يحافظ على المصداقية | تبويب أخبار في لوحة الإدارة مع تاريخ ومصدر وصورة موافق عليها |
| حملات جماعية | توسع الوصول | مرحلة متقدمة بعد تأمين الحسابات والقياس والتحقق من التبرعات |
