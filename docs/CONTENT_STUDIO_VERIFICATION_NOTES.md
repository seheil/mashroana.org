# ملاحظات التحقق لمركز إدارة المحتوى

## 26 أغسطس 2026 — صفحة «عن المؤسسة»

تمت مراجعة صفحة **عن المؤسسة** محلياً بعد ربط الرسالة التعريفية وبطاقات مجالات العمل والنصوص المؤسسية بإعدادات مركز المحتوى. عرض سطح المكتب عرض البطاقات الأربع، كتلة الحوكمة، مجلس الأمناء، وبطاقتي التواصل المؤسسي بترتيب مقروء ومتزن. عرض الهاتف حافظ على تسلسل رأسي واضح دون قص أفقي ظاهر، وبقيت عناوين البطاقات ووصفها وأزرار الدعوة إلى الإجراء قابلة للقراءة.

هذا تحقق بصري محلي للبدائل الافتراضية فقط. يبقى اختبار الحفظ الفعلي في Firestore، وإعادة التحميل، والتحقق من العرض للزائر غير المسجل مع حساب إدارة موثّق عند توفر جهاز الحاسوب.

## 27 أغسطس 2026 — تحقق من النسخة السابقة وخدمة Firebase

تبين أن المستودع العام السابق `seheil/mashroana.org` نسخة HTML ثابتة، تتضمن مجلد `assets`، وآخر تغيير فيها كان رفع ملفات يدوياً. يوثق ملف README الخاص بها أن التحديثات كانت تُنشر عبر دفع التعديلات إلى فرع `main`، وليس عبر مكتبة وسائط ديناميكية أو Firestore. كذلك أظهر فحص مشاريع Firebase أن `mashroana-site` و`Mashroana-web` لا تحتويان قاعدة Firestore بعد، بينما `mashrouana-app` تحتوي بيانات غير مرتبطة بالمؤسسة (`studyYears` و`subjects`). لذلك لا يجوز إعادة استخدام قاعدة التطبيق الآخر؛ يلزم إنشاء Firestore مستقلة في `mashroana-site`، بعد تأكيد المؤسسة، قبل تنفيذ اختبارات الحفظ الحية.
