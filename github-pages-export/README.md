## 🚀 كيفية النشر على GitHub Pages

### الخطوة 1: إنشاء مستودع GitHub

1. اذهب إلى [GitHub.com](https://github.com)
2. انقر على **New Repository**
3. أدخل اسم المستودع: `mashroana.org` أو `mashrouana-foundation`
4. اختر **Public**
5. انقر **Create Repository**

### الخطوة 2: رفع الملفات

#### الطريقة الأولى: عبر Git (موصى به)

```bash
# استنسخ المستودع
git clone https://github.com/YOUR_USERNAME/mashroana.org.git
cd mashroana.org

# أضف الملفات
git add .

# أنشئ commit
git commit -m "Initial commit: Mashrouana Foundation website"

# ارفع الملفات
git push origin main
```

#### الطريقة الثانية: عبر واجهة GitHub

1. اذهب إلى مستودعك على GitHub
2. انقر على **Add file > Upload files**
3. اسحب جميع الملفات والمجلدات هنا
4. اكتب رسالة commit
5. انقر **Commit changes**

### الخطوة 3: تفعيل GitHub Pages

1. اذهب إلى **Settings** في المستودع
2. اختر **Pages** من القائمة اليسرى
3. تحت **Source**، اختر **Deploy from a branch**
4. اختر **Branch: main** و **Folder: / (root)**
5. انقر **Save**

### الخطوة 4: ربط الدومين mashroana.org

#### في GitHub:

1. في صفحة **Settings > Pages**
2. تحت **Custom domain**، أدخل: `mashroana.org`
3. انقر **Save**
4. تأكد من تفعيل **Enforce HTTPS**

#### في Cloudflare (لوحة تحكم الدومين):

1. اذهب إلى **DNS** في Cloudflare
2. أضف سجل **CNAME**:
   - **Name**: `mashroana.org`
   - **Target**: `YOUR_USERNAME.github.io`
   - **Proxy status**: Proxied

أو استخدم سجلات **A** إذا كنت تفضل:
- `185.199.108.153`
- `185.199.109.153`
- `185.199.110.153`
- `185.199.111.153`

### الخطوة 5: التحقق

بعد 5-10 دقائق:

1. اذهب إلى `https://mashroana.org`
2. يجب أن ترى الموقع يعمل بشكل صحيح
3. تحقق من أن الاتصال آمن (🔒 في المتصفح)
