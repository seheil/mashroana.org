# دليل المساهمة

شكراً لاهتمامك بالمساهمة في موقع مؤسسة مشروعنا إلى الجنة! 🙏

## كيفية المساهمة

### 1. Fork المستودع

1. اذهب إلى [المستودع الرسمي](https://github.com/mashrouana/mashroana.org)
2. انقر على **Fork** في الزاوية العلوية اليسرى
3. سيتم إنشاء نسخة من المستودع في حسابك

### 2. استنسخ المستودع محلياً

```bash
git clone https://github.com/YOUR_USERNAME/mashroana.org.git
cd mashroana.org
```

### 3. أنشئ فرع جديد

```bash
git checkout -b feature/your-feature-name
```

### 4. أجرِ التغييرات

عدّل الملفات التي تريد تحسينها:
- `index.html` - الصفحة الرئيسية
- `assets/` - الملفات الثابتة

### 5. اختبر التغييرات

افتح `index.html` في المتصفح للتحقق من التغييرات:

```bash
# على macOS
open index.html

# على Linux
xdg-open index.html

# على Windows
start index.html
```

### 6. أرسل Pull Request

```bash
# أضف التغييرات
git add .

# أنشئ commit
git commit -m "إضافة: وصف التحسين"

# ارفع الفرع
git push origin feature/your-feature-name
```

ثم اذهب إلى GitHub وأنشئ **Pull Request**.

## معايير المساهمة

### الكود

- استخدم **HTML5** الحديث
- اتبع معايير **WCAG 2.1** للوصول
- تأكد من **التوافق مع جميع المتصفحات**
- اختبر على **الأجهزة المحمولة**

### الرسائل

- اكتب رسائل commit واضحة وموجزة
- استخدم الأمر الماضي: "أضفت" بدلاً من "أضيف"
- مثال: `إضافة: قسم جديد للمشاريع`

### التصميم

- حافظ على **الأسلوب الموحد**
- استخدم **الألوان الأخضر والأبيض**
- تأكد من **سهولة القراءة**
- اختبر على **أحجام شاشات مختلفة**

## أنواع المساهمات المرحب بها

### 🐛 إصلاح الأخطاء

وجدت خطأ؟ أخبرنا! يمكنك:
- فتح **Issue** لوصف المشكلة
- إرسال **Pull Request** بالإصلاح

### ✨ ميزات جديدة

لديك فكرة لتحسين الموقع؟
- افتح **Issue** لمناقشة الفكرة
- انتظر الموافقة من الفريق
- ابدأ العمل على **Pull Request**

### 📝 تحسينات التوثيق

ساعد في تحسين الوثائق:
- تحديث `README.md`
- إضافة تعليقات في الكود
- تحسين التعليمات

### 🎨 تحسينات التصميم

حسّن مظهر الموقع:
- تحديث الألوان
- تحسين الخطوط
- إضافة رسوميات جديدة

## عملية المراجعة

1. **الفحص التلقائي**: سيتم فحص الكود تلقائياً
2. **المراجعة اليدوية**: سيراجع الفريق التغييرات
3. **الطلبات**: قد نطلب تحسينات إضافية
4. **الموافقة**: بعد الموافقة، سيتم دمج التغييرات

## الأسئلة الشائعة

### كيف أبدأ؟

1. اختر **Issue** من قائمة المشاكل
2. اترك تعليق: "أود العمل على هذا"
3. انتظر الموافقة
4. ابدأ العمل!

### ماذا لو كان لدي سؤال؟

- اترك تعليق في **Issue**
- أرسل رسالة عبر **Discussions**
- تواصل معنا عبر **البريد الإلكتروني**

### كيف أختبر التغييرات؟

```bash
# افتح الملف في المتصفح
open index.html

# أو استخدم خادم محلي
python -m http.server 8000
# ثم اذهب إلى http://localhost:8000
```

## قواعس السلوك

- كن **محترماً** و**لطيفاً**
- تقبل **النقد البناء**
- ركز على **الموضوع**
- ساعد **الآخرين**
