# مؤسسة مشروعنا إلى الجنة - موقع الويب الرسمي

موقع ويب حديث وتفاعلي لمؤسسة مشروعنا إلى الجنة للأعمال الخيرية، يوفر تجربة تبرع سلسة مع مستشار ذكي ولوحة تحكم إدارية.

## 🌟 الميزات الرئيسية

### 1. **نظام التبرع الذكي**
- 13 مشروع خيري متنوع مع وصف وأثر محدد
- نموذج تبرع ديناميكي مع طرق دفع متعددة (InstaPay, Vodafone Cash, WhatsApp)
- حساب الأثر الفوري لكل تبرع

### 2. **المستشار الذكي (Chatbot)**
- مستشار ذكي متخصص في المشاريع الخيرية
- قاعدة معارف شاملة عن جميع المشاريع
- أسئلة استباقية وردود ذكية

### 3. **البستان الرقمي التفاعلي**
- عرض بصري للأشجار والنخيل والآبار
- عداد حي للأشجار المزروعة
- رسومات متحركة جذابة

### 4. **لوحة تحكم الإدارة**
- إدارة سهلة للمشاريع والإحصائيات
- تحديث عناصر البستان الرقمي
- واجهة بديهية وسهلة الاستخدام

### 5. **الشفافية والثقة**
- عرض الـ 13 ميدان الرسمية للمؤسسة
- معلومات التسجيل والترخيص
- تقارير الإنجازات والأثر الاجتماعي

## 🛠️ المتطلبات

- Node.js 18+ و npm/pnpm
- قاعدة بيانات MySQL أو TiDB
- مفتاح API لـ Manus (للمصادقة والتكامل)

## 📦 التثبيت والإعداد

### 1. استنساخ المشروع
```bash
git clone https://github.com/yourusername/mashrouana-foundation.git
cd mashrouana-foundation
```

### 2. تثبيت المتغيرات البيئية
```bash
cp .env.example .env.local
```

ثم قم بتحديث المتغيرات بقيمك الخاصة:
```env
# قاعدة البيانات
DATABASE_URL=mysql://user:password@localhost:3306/mashrouana

# المصادقة
JWT_SECRET=your-secret-key-here
VITE_APP_ID=your-app-id
OAUTH_SERVER_URL=https://api.manus.im
VITE_OAUTH_PORTAL_URL=https://portal.manus.im

# Manus APIs
BUILT_IN_FORGE_API_URL=https://api.manus.im
BUILT_IN_FORGE_API_KEY=your-api-key
VITE_FRONTEND_FORGE_API_KEY=your-frontend-key
VITE_FRONTEND_FORGE_API_URL=https://api.manus.im

# معلومات المالك
OWNER_NAME=مؤسسة مشروعنا إلى الجنة
OWNER_OPEN_ID=owner-id

# تحليلات
VITE_ANALYTICS_ENDPOINT=https://analytics.manus.im
VITE_ANALYTICS_WEBSITE_ID=your-website-id
```

### 3. تثبيت المتطلبات
```bash
pnpm install
```

### 4. إعداد قاعدة البيانات
```bash
pnpm drizzle-kit generate
# ثم قم بتطبيق الهجرات عبر لوحة التحكم
```

### 5. تشغيل الخادم
```bash
pnpm dev
```

الموقع سيكون متاحاً على `http://localhost:3000`
